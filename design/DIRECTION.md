# 共用桌面：Build Night

北極星：報名就是把自己的名字放進今晚的共同工作桌。

受眾是想動手做作品的學生與創作者。主角是「一個點子變成可展示的原型」；唯一主動作是前往表單並完成本機報名互動。這是已有示範的重新設計，不代表使用者已決定正式 hackathon 題目。

## 灰度骨架

```text
┌ 品牌 ───────────── 活動安排  參加活動 ┐
│                                      │
│        一個點子，                    │
│        一桌好夥伴。                  │
│     活動時間、形式、一句中文說明        │
│             [留個位置給我]            │
│                                      │
│   [共同工作桌插畫：協作中的創作者]    │
│                  [空椅＋姓名座位牌]   │
└──────────────────────────────────────┘
│ 活動安排標題      18:30 / 19:00 / 21:00│
│ 報名說明          姓名／Email／結果    │
└──────────────────────────────────────┘
```

手機保留相同閱讀順序，插畫依比例縮小，姓名牌移到插畫下緣；表單放單欄。桌機首屏可見主 CTA、時間及核心主視覺。

## 視覺與互動

- 字體：本機 Space Grotesk 500/600/700 用於英文品牌與拉丁字；Segoe UI / Microsoft JhengHei 用於中文大標及正文。中文展示字桌機76px、手機39px；正文16–18px。
- 色彩：霧藍 `#EEF3F7` 作共同工作區、深藍 `#18334C` 作文字、動作藍 `#2659DD` 作按鈕、淡紫 `#DBD4EF` 作原型便箋、暖黃 `#F5DF7A` 作想法便箋、莓紅 `#B83B58` 作錯誤。來自工作桌上的紙張與標記，而非科技發光效果。
- 間距：8px 基準；桌機內容寬1184px，主區域上下72–96px，手機左右24px、區塊48px。
- 控件：12px 圓角、輸入與按鈕至少48px高、清楚鍵盤 focus，hover不改變尺寸。
- 記憶點：插畫中一張藍色空椅邀請使用者坐下；座位牌完成後顯示姓名與首字，成功狀態有「看看我的位置」連結帶回桌面。成功文字明示資料尚未送出或儲存，避免假報名。
- 狀態：預設、欄位聚焦、無效姓名、無效信箱、成功、重新編輯；錯誤保留輸入，成功後可再次修改。
- 動效：一次性的工作桌組裝、按鈕按壓與便箋狀態變換；GSAP ScrollTrigger 在議程閱讀時僅移動背景進度線，文字與表單不做視差。prefers-reduced-motion 下完全靜態。
- 素材：內建 imagegen 生成的專屬透明插畫，完整提示詞在 `HERO-ASSET.md`。圖片只表達場景；真實 HTML 提供姓名、按鈕、內容與表單。本機字體、GSAP 和插畫均已打包，無外部 runtime 請求，不需額外圖像 API key。

## 參考與取捨

實際查看 Hack Club 和 Luma 首屏。Hack Club 借鑑社群活動的一個清楚加入入口、把成果／參與感放在主視覺；不複製相片拼貼、紅色品牌與波浪底。Luma 借鑑單一主動作與短內容；不採用大面積空白、彩虹文字或其字標。

產品研究保存於本次 workspace 的 work/design-reference-shots/，原站圖片不隨工具包分發。互動參考沒有取得它們登入後的完整流程，未據此推測操作；以本套實際表單與瀏覽器測試驗證。

UI UX Pro Max 的 query 命中 Hero-Centric Design / Vibrant & Block-based；採用單一CTA、明確鍵盤狀態、減少動態與清晰錯誤。不採用通用紫橘配色、Inter/Playfair 組合、倒數計時或全頁 scroll-snap：與共用桌面及未知活動日期不符。

獨立概念生成：design_concepts；獨立概念把關：concept_gate，通過。視覺及 UX 的實際評審另外記在本次 evidence。
